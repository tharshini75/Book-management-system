# 📚 Book Management System

## 📖 Project Description

The Book Management System is a Python desktop application developed to manage book records efficiently. It allows users to add, search, update, delete, and view book details through a simple graphical user interface.

---

## ❗ Problem Statement

Managing book records manually is difficult and time-consuming. A simple digital system is required to organize and manage book information efficiently.

---

## 💡 Solution

This project provides a user-friendly graphical interface that helps users manage book records easily using Python and SQLite.

---

## ✨ Features

- Add Book
- View Books
- Search Book
- Update Book Details
- Delete Book
- User-Friendly GUI

---

## 🛠️ Tools Used

- Python
- Tkinter
- SQLite
- Visual Studio Code
